# 오늘의 할 일 (개인 보드)

이미경님 전용 개인 할 일 보드입니다. 체크하면 스르륵 사라지고, 남은 일은 기기에 저장됩니다.

## 보안 구조

- 할 일 내용은 `data.json`(로컬 원본)에서 **PBKDF2-HMAC-SHA256(310,000회) + AES-256-GCM** 으로 암호화되어 `data.enc.json` / `data-enc.js` 에만 담깁니다.
- 저장소에는 **암호문만** 올라갑니다. `.gitignore` 가 `data.json`, 비밀번호 파일, salt 를 막습니다.
- 브라우저는 비밀번호로 복호화한 뒤 화면에 그립니다. 완료 상태·추가한 항목은 그 기기의 `localStorage` 에만 저장됩니다.
- "이 기기에서 잠금 해제 유지"를 켜면 복호화 키만 저장하고, 데이터는 저장하지 않습니다.

## 갱신 방법

1. `data.json` 을 고친다. (할 일·카테고리·마감일 `dueDate`)
2. `python3 build_encrypted.py` 로 암호문을 다시 만든다.
3. `./deploy.sh` 로 커밋·푸시하고 사이트를 확인한다.

## 캐시·새로고침(휴대폰에 옛 화면이 남는 문제)

- **열 때마다 최신 데이터를 직접 받습니다.** 보드를 열면 `data.enc.json?t=시각` 을 `cache: 'no-store'` 로
  받아 비밀번호로 풀어 그립니다. 정적 `data-enc.js` 는 통신이 안 될 때만 쓰는 예비입니다.
  그래서 할 일을 고쳐 배포하면, 홈 화면 바로가기를 지웠다 다시 깔지 않아도 열기만 하면 새 내용이 뜽니다.
- **앱으로 돌아오면 다시 맞춥니다.** 백그라운드에서 돌아왔을 때(`visibilitychange` / `pageshow` / `focus`)
  와 화면을 띄워 둔 동안 5분마다 최신 암호문을 확인해, 내용이 바뀌었을 때만 다시 그립니다.
- **헤더 오른쪽 `↻` 새로고침 버튼**: 코드 판이 바뀌었으면 `?v=새버전` 주소로 한 번 다시 열고,
  데이터만 바뀌었으면 바로 다시 받아 그립니다. 결과는 “업데이트됐어요 / 최신 상태예요” 로 잠시 표시됩니다.
- `./deploy.sh` 는 배포할 때마다 `version.json` 과 `index.html` 의 `<meta name="board-version">`,
  그리고 `styles.css?v=…` / `data-enc.js?v=…` / `app.js?v=…` 의 버전 값을 **같은 값**으로 새로 찍습니다.
- `index.html` 자체는 GitHub Pages 가 10분간 캐시하므로, 페이지 맨 아래 스크립트가 `version.json` 을
  `no-store` 로 확인해 새 버전이면 `?v=새버전` 주소로 스스로 다시 엽니다. (한 번만, 반복 없음)
- `app.js` 첫 줄의 `board-version:` 값도 배포 때 같이 바뀌어, 라이브에 새 코드가 내려왔는지 바로 확인할 수 있습니다.

`dueDate` 가 오늘보다 이전인데 완료하지 않은 항목은 보드 맨 위 **🚨 긴급 (이월)** 로 자동으로 올라옵니다.

`+ 할 일 추가` 로 직접 넣은 항목도 따로 모이지 않고 마감일이 같은 섹션에 합쳐집니다.
(내일 → **📌 내일까지**, 오늘 → **📅 오늘까지**, 그 밖의 날짜 → **🗓️ M/D(요일)까지**, 지난 날짜 → **🚨 긴급 (이월)**.)
카테고리를 적으면 그 섹션의 같은 카테고리 묶음으로, 비우면 섹션 안 **내가 추가** 묶음으로 들어갑니다.
`날짜` 를 골랐는데 날짜 칸이 비어 있으면 오늘로 넣지 않고 날짜 칸을 열어 줍니다.
기기에 저장된 예전 항목에 마감일이 없으면 추가한 날(created)을 마감일로 되살립니다(매일 오늘로 밀리지 않음).

비밀번호 파일은 저장소 밖 `/workspace/work/my-todo/.board-pass` 에 있습니다.
