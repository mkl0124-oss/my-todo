# 오늘의 할 일 (개인 보드)

이미경님 전용 개인 할 일 보드입니다. 체크하면 스르륵 사라지고, 남은 일은 기기에 저장됩니다.

## 보안 구조

- 할 일 내용은 `data.json`(로컬 원본)에서 **PBKDF2-HMAC-SHA256(310,000회) + AES-256-GCM** 으로 암호화되어 `data.enc.json` / `data-enc.js` 에만 담깁니다.
- 저장소에는 **암호문만** 올라갑니다. `.gitignore` 가 `data.json`, 비밀번호 파일, salt 를 막습니다.
- 브라우저는 비밀번호로 복호화한 뒤 화면에 그립니다. 완료 상태·추가한 항목은 그 기기의 `localStorage` 에만 저장됩니다.
- "이 기기에서 잠금 해제 유지"를 켜면 복호화 키만 저장하고, 데이터는 저장하지 않습니다.

## 갱신 방법

1. `data.json` 을 고친다. (할 일·카테고리·마감일 `dueDate`)
2. `python3 build_encrypted.py` 로 암호문을 다시 만든다.
3. `./deploy.sh` 로 커밋·푸시하고 사이트를 확인한다.

`dueDate` 가 오늘보다 이전인데 완료하지 않은 항목은 보드 맨 위 **🚨 긴급 (이월)** 로 자동으로 올라옵니다.

`+ 할 일 추가` 로 직접 넣은 항목도 따로 모이지 않고 마감일이 같은 섹션에 합쳐집니다.
(내일 → **📌 내일까지**, 오늘 → **📅 오늘까지**, 그 밖의 날짜 → **🗓️ M/D(요일)까지**, 지난 날짜 → **🚨 긴급 (이월)**.)
카테고리를 적으면 그 섹션의 같은 카테고리 묶음으로, 비우면 섹션 안 **내가 추가** 묶음으로 들어갑니다.

비밀번호 파일은 저장소 밖 `/workspace/work/my-todo/.board-pass` 에 있습니다.
